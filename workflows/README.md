# Workflow presets của Node Studio

Các tệp JSON trong thư mục này là preset nguồn có thể review và tái tạo trong
Local AI Hub. Chúng không chứa đường dẫn máy, media, model hoặc bí mật.

Workflow do người dùng chỉnh trong Node Studio được autosave trong `localStorage`
của WebView; có thể Export JSON để lưu ngoài Git. Nếu cần một tệp local cạnh
preset, dùng hậu tố `.local.json`, tệp đó bị Git bỏ qua.
