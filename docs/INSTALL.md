# Installation

1. Clone the private repository.
2. Copy the tracked configuration examples to local, ignored files.
3. Set paths such as `LOCAL_AI_HOME`, `FFMPEG_PATH`, `WHISPER_HOME` and
   `ANIMESR_HOME` for the machine.
4. Install Python environments and model weights with the setup scripts or the
   official upstream installers.
5. Run a bounded health/smoke check.

The repository intentionally does not contain environments, models, cache,
media or credentials.
