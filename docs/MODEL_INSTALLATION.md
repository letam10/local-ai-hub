# Model installation

Model rows are catalog-owned. `AUTO_INSTALL_READY` is shown only when the
server has a pinned source, exact leaves, integrity metadata, disk plan and a
real executor. Other rows expose Manual Import, provider authorization or
license review. A browser never sends a local path, command or download URL.

Native desktop import returns a short-lived opaque selection ID. The server
validates every catalog leaf, rejects reparses and existing destinations, then
copies into a previously absent managed model root or registers an already
managed compatible installation without copying bytes.
